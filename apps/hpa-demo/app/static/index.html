    How it works

    Each request uses about 20 ms of CPU. The slider sets how many this page sends per second. Above 50% average CPU the autoscaler adds pods (up to 5); after a quiet minute it removes them.
    Live data from the Kubernetes API (read-only, this namespace only) and metrics-server, every 2 s. Load only runs while this page is open. Source: zulhardy-lab/devops-projects · apps/hpa-demo
